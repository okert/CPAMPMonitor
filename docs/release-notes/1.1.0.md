## 新增功能（macOS）

- 显示 Codex 剩余可用重置次数。
- 逐条查看重置机会的到期时间和剩余有效期；接口未返回的时间显示为未知。
- 点击重置先核实可用次数，再弹出确认框，明确提示消耗 1 次机会，默认取消。
- 重置成功后同步网关冷却状态并刷新额度和次数；同步失败单独提示，不自动重复消耗。

## 下载与验证

- macOS：Apple Silicon（arm64）和 Intel（x86_64）。
- Windows：原生 WPF x64 和 ARM64 安装包，沿用现有功能；本次重置功能仅适用于 macOS。
- ZIP 包附 SHA-256 校验文件。macOS 使用 ad-hoc 签名，未 notarize；Windows 未签名。
- 重置解析与模拟接口测试已覆盖；未使用真实账号消耗重置次数进行验证。

## What's New (macOS)

Codex reset-credit balances, individual expiration details, and a confirmation-protected reset action. Successful resets synchronize gateway cooldowns and refresh quota. Uncertain results are not retried automatically.

Windows x64 and ARM64 packages retain their existing feature set; reset credits are currently macOS-only. Real credit consumption has not been tested against a live account.
