## 新增功能（macOS）

- 菜单栏前置图标、百分号可分别隐藏，只保留额度数字。
- 数字边框支持无边框、方形和圆形，使用紧凑尺寸减少菜单栏占用。
- 外观修改立即生效并自动保存，无需重新连接服务。
- 隐藏图标后，无有效额度时显示 `--`，不会误显示为 0 或丢失菜单栏入口。
- 保留系统自适应模板颜色、状态提示和辅助功能标签。

## 下载与验证

- macOS：Apple Silicon（arm64）和 Intel（x86_64）。
- Windows：原生 WPF x64 和 ARM64 包，沿用现有功能；本次菜单栏外观设置仅适用于 macOS。
- ZIP 包附 SHA-256 校验文件。macOS 使用 ad-hoc 签名，未 notarize；Windows 未签名。
- 已通过核心测试、外观配置持久化测试及方形/圆形边框渲染检查。

## What's New (macOS)

Customize the menu bar with independently hidden icons and percent signs, plus compact square or circular number borders. Appearance changes apply immediately and persist without reconnecting. Missing quota remains explicitly unavailable.

Windows x64 and ARM64 packages retain their existing feature set.
